# MacroDroid로 카드 알림 자동 입력하기

웹페이지는 휴대폰 알림·문자를 직접 읽을 수 없어서, 무료 자동화 앱 **MacroDroid**가 카드 알림을 받으면 그 내용을 가계부 서버(`/api/ingest`)로 전달하도록 설정합니다. 처음 한 번만 하면 이후엔 결제할 때마다 자동으로 기록됩니다.

> 전제: 가계부가 인터넷에서 접속 가능한 주소(예: `https://내가계부.vercel.app`)로 배포돼 있어야 합니다. `localhost`로는 폰에서 보낼 수 없습니다.

## 준비물

- 서버의 `INGEST_SECRET` 값 (`.env` 또는 배포 환경변수에 넣은 값)
- 가계부 주소. 앱의 **설정 화면 맨 아래**에 전송 주소가 나와 있습니다.

## 1. 카드사 앱 알림 켜기

각 카드사/은행 앱에서 **결제(승인) 푸시 알림**을 켭니다. 또는 승인 문자(SMS) 서비스를 신청해도 됩니다. 둘 다 와도 중복 등록되지 않습니다.

## 2. MacroDroid 설치와 권한

1. Play 스토어에서 **MacroDroid** 설치
2. 휴대폰 설정 → 앱 → MacroDroid → **배터리: 제한 없음(최적화 안 함)**. 이걸 안 하면 백그라운드에서 꺼져서 알림을 놓칩니다.
3. 첫 매크로를 만들 때 요청하는 **알림 접근 권한**을 허용

## 3. 매크로 A — 카드사/은행 앱 알림

**트리거**: `알림` → `알림 수신`(Notification Received)
- 앱 선택: 쓰는 카드사·은행·페이 앱을 모두 체크 (예: 신한 SOL페이, 삼성카드, 현대카드, KB Pay, 카카오뱅크, 토스 …)
- 텍스트 조건: `모든 내용`(Any)

**액션**: `연결` → `HTTP 요청`(HTTP Request)
- 메서드: `POST`
- URL:
  ```
  https://내가계부주소/api/ingest?token=INGEST_SECRET값
  ```
- 콘텐츠 유형(Content type): `text/plain`
- 본문(Body): 매직 텍스트(… 버튼)로 아래 두 개를 줄바꿈으로 넣습니다
  ```
  [알림 제목]
  [알림 텍스트]
  ```
  MacroDroid 버전에 따라 `[not_title]`, `[notification]` 같은 이름으로 보입니다.
- (선택) 알림에 카드사 이름이 안 나오는 앱이라면, 그 앱만 따로 매크로를 만들어 본문 첫 줄에 `신한카드`처럼 직접 적어주세요. (URL에 한글을 넣으면 오류가 날 수 있습니다.)

저장 후 **매크로 테스트**(▶)를 눌러보거나 실제로 소액 결제를 해서 가계부에 뜨는지 확인하세요.

## 4. (선택) 매크로 B — 승인 문자(SMS)

카드 푸시 대신 문자를 받는 경우에만 만드세요.

- **트리거**: `전화/SMS` → `SMS 수신` → 발신자: 모든 번호, 내용에 `원` 포함
- **액션**: 매크로 A와 같은 HTTP 요청. URL 끝에 `&source=sms` 추가, 본문은 매직 텍스트 `[SMS 메시지]`(`[sms_message]`)

## 동작 방식

- 서버는 원문에서 금액·가맹점·일시·카드명·할부·승인/취소/입금을 읽어 자동 분류합니다.
- **승인취소**가 오면 원래 승인 건을 찾아 함께 집계에서 빼줍니다.
- 같은 결제가 푸시와 문자로 두 번 와도 한 번만 저장됩니다.
- 광고/안내처럼 금액이 없는 알림은 무시합니다.
- 금액은 있는데 무슨 거래인지 모르겠는 건 **검토 필요**로 저장되니, 대시보드에서 눌러 분류해 주세요. 그때 "앞으로 항상 이 분류로"를 체크하면 다음부터 자동 분류됩니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 아무것도 안 들어옴 | 배터리 최적화 해제, 알림 접근 권한, 트리거에 해당 앱이 체크됐는지 |
| MacroDroid 로그에 401 | URL의 `token`이 서버의 `INGEST_SECRET`과 정확히 같은지 |
| 들어오는데 카드명이 비어 있음 | 본문 첫 줄에 카드사 이름을 직접 적기 |
| 가맹점/분류가 이상함 | 내역을 눌러 고치고 "항상 이 분류로" 체크, 또는 설정 → 자동 분류 규칙 추가 |

손으로 확인해 보고 싶으면 PC에서 이렇게 보내볼 수 있습니다:

```bash
curl -X POST "https://내가계부주소/api/ingest?token=INGEST_SECRET값" \
  -H 'content-type: text/plain' \
  --data-binary $'신한카드(1234)승인\n13,500원 일시불\n11/27 08:30\n스타벅스'
```
