# familymoneymany — 우리집 경제공부 💰

주식·부동산 투자를 목표로 **매일 30분~1시간** 경제공부를 하고, 공부한 내용을 데이터로 쌓는 저장소입니다.

🌐 **웹사이트:** https://hongbbol.github.io/familymoneymany/ (아래 "최초 1회 설정" 후 열림)

## 이렇게 사용해요

1. **웹사이트를 열면** 오늘 요일에 맞는 공부 루틴이 보입니다.
   - 매일: 경제 뉴스 브리핑 15분
   - 월·수: 주식의 날 / 화·목: 부동산의 날 / 금: 복습의 날 / 주말: 선택 심화
2. **주식·부동산 탭**에서 12주 커리큘럼을 주차별로 공부합니다. (기초 용어 → 분석 → 실전 준비)
3. 공부가 끝나면 **"✏️ 오늘 공부 기록하기"** 버튼을 누르고 폼을 작성해 제출합니다.
   - 자동으로 `data/logs.json`에 저장되고, 대시보드(총 일수·연속 기록·용어 수)에 반영됩니다.
4. **공유:** 웹사이트 주소를 가족·친구에게 보내면 같은 루틴과 기록을 볼 수 있어요.

## 최초 1회 설정 (저장소 주인만, 1분)

1. 이 변경사항(PR)을 `main`에 머지합니다.
2. 저장소 **Settings → Pages** 에서 Source를 **Deploy from a branch**, Branch를 **`main` / `(root)`** 로 선택하고 Save.
3. 1~2분 뒤 위 웹사이트 주소가 열립니다.

> 기록은 저장소 주인(또는 Collaborator로 초대된 가족)이 작성한 것만 저장됩니다.
> 가족과 함께 기록하려면 Settings → Collaborators 에서 가족의 GitHub 계정을 초대하세요.

## 파일 구조

| 경로 | 내용 |
|---|---|
| `index.html`, `assets/` | 웹사이트 |
| `data/curriculum.json` | 주식·부동산 12주 커리큘럼 (수정하면 사이트에 바로 반영) |
| `data/logs.json` | 공부 기록 데이터 (자동으로 쌓임) |
| `.github/ISSUE_TEMPLATE/study-log.yml` | 공부 기록 입력 폼 |
| `.github/workflows/study-log.yml`, `scripts/add_study_log.py` | 기록 자동 저장 |

⚠️ 공부 루틴을 돕기 위한 자료이며, 특정 상품에 대한 투자 권유가 아닙니다.
